# WRizz Simulator

Deploy this folder to Vercel. Build command: `npm run build`. Output directory: `dist`.

This package contains the latest prebuilt simulator with WRizz branding restored, the 0.7-second opening trim, the current slower pacing, and the restored status bar. The original editable React source was no longer present in the workspace; this is a prebuilt deployment package. The optional AI Studio bridge is recovered from the previous source archive and requires its documented environment variables.
