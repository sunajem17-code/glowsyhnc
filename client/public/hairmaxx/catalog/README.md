# HairMaxx portrait catalog pilot

This is a generated 18-image pilot set: six appearance labels, each with short,
medium, and long examples. Portraits use transparent backgrounds and a shared
head-and-shoulders framing. The shirt continues into the bottom crop.

Hair pattern, strand thickness, and density vary by example and should be
treated as the asset's descriptive tags—not inferred from the appearance label.
The images are 1094 x 1438 PNGs with alpha transparency; they are not native 4K.

These are catalog candidates only. They have not been wired into HairMaxx's
selection UI or verified in the app.
